
# Enterprise Network Project

## Project Overview
Design and implementation of an enterprise network using Cisco Packet Tracer.

## Project Objectives
- Design a structured enterprise network.
- Configure VLANs and Trunking.
- Implement Inter-VLAN Routing.
- Configure DHCP and IP Addressing.
- Apply network security policies.
- Perform network connectivity testing.

## Technologies
- Cisco Packet Tracer
- Cisco IOS
- VLANs
- Inter-VLAN Routing
- DHCP
- ACL
- SSH
- Port Security

## Project Structure
- Packet-Tracer: Network simulation files.
- Configurations: Router and switch configurations.
- Documentation: Network design and technical documentation.
- Screenshots: Project screenshots.
